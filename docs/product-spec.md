# TContext 제품 명세

## 문제와 목표

AI API를 사용하는 핵심 이유는 교사의 짧고 간단한 답변에서도 가치·행동·제약을 연결하여 적합한 콘텍스트를 추론하고 확장하기 위해서다. 단순한 답변 요약에 그치지 않고 교육적 의미와 실행 가능한 AI 협업 지침을 만든다. 직접 진술, 근거 있는 해석, 선택이 필요한 가설을 구분하여 교사가 검토한다. 짧은 답변을 근거 없는 답변으로 취급하지 않는다.

교사는 생성형 AI를 수업 설계에 활용할 때마다 자신의 교육관, 수업 방식, 학급 맥락, 현실적 제약을 다시 설명해야 한다. TContext는 약 20분의 반구조화 인터뷰를 통해 이 맥락을 구조화하고, 여러 AI 서비스에서 재사용할 수 있는 Markdown 문서로 만든다.

이 서비스는 교사를 유형화하거나 평가하지 않는다. 점수, 등급, 성격 유형, 순위를 만들지 않으며 교사가 모든 문장과 분석 태그의 최종 결정권을 갖는다.

## 대상 사용자

- 학교급: 유치원, 초등학교, 중학교, 고등학교
- 역할: 담임교사, 교과전담·교과교사, 특수교사, 상담교사, 보건교사, 사서교사, 관리자·교육 리더, 기타
- 담당 교과: 중학교와 고등학교에서 통제된 선택값으로 받으며, 교과 수업을 맡지 않는 역할도 선택할 수 있다.
- 로그인 없이 즉시 사용할 수 있다.

## 핵심 사용자 흐름

1. 서비스 목적과 개인정보 입력 금지 항목을 확인한다.
2. 학교급과 역할을 선택한다. 중학교와 고등학교에서는 담당 교과도 선택한다.
3. 한 화면에 한 질문씩 답한다. 원문 답변은 현재 탭의 메모리에만 남고 새로고침하면 사라진다.
4. 각 단계 이동 시 로컬 개인정보 탐지를 실행한다. 학교급·학년·교과·대략적인 인원·수업 환경·익명 집단 경향은 그대로 두고, 직접 식별정보와 고위험 단서 조합은 경고로 보여 준다. 연수용이므로 차단하지 않으며 교사는 답변을 고치거나 그대로 계속할 수 있다.
5. 최대 네 번의 AI 후속 질문으로 구체적인 수업 경험을 보완한다.
6. AI가 7개 모듈의 구조화 프로필 초안을 만든다.
7. 교사가 직접 진술, AI 추론, 확인 필요 문장과 AI 작성 제목·요약·원칙·지침을 구분해 검토·수정·삭제한다. 미확인 문장은 범위를 확인한 뒤 한 번에 승인할 수 있지만, AI 추론 표시는 유지되고 개인정보 경고나 저장 동의는 자동 승인되지 않는다.
8. 개인정보 최종 검토 후 Markdown을 다운로드하거나 복사한다. 경고가 남으면 문장을 수정하거나, 위험을 명시적으로 확인하고 `needs_review` 상태의 로컬 결과만 만들 수 있다.
9. 선택적으로만, 별도의 명시적 동의 후 개인정보 검토가 `clear`인 최종 프로필과 확인된 태그를 Supabase에 기여한다. 경고를 확인하고 진행한 결과는 기여할 수 없다.
10. 저장했다면 제출 ID와 일회성 삭제 코드를 내려받는다.
11. 별도의 로컬 저장을 켜면 확정본과 편집 초안을 이 브라우저에 최대 10개 보관하고 `/profiles`에서 다시 열어 수정·확정한다. JSON 백업 다운로드와 저장하지 않고 가져오기는 로컬 저장 동의 없이도 가능하다.
12. 문서가 있는 동안 상단의 현재 문서 메뉴로 결과 또는 검토 화면에 돌아간다. 인터뷰·검토·관리자 화면에서는 숨기며, 새로고침하면 메모리 세션과 함께 사라진다. 640px 미만에서는 현재 문서 메뉴가 보일 때만 인터뷰 시작 메뉴를 숨긴다.

## 7개 프로필 모듈

1. 기본 프로필과 현재 역할
2. 교육관과 학생관
3. 선호하는 수업 방식
4. 학급 또는 수업 집단 맥락
5. 학생 참여와 정서 지원
6. 수업 자료·평가·피드백과 의사소통
7. 현실적 환경·제약과 원하는 AI 활용

## 증거 상태

- `direct`: 교사가 직접 밝힌 내용
- `inferred`: 답변을 바탕으로 AI가 해석한 내용
- `needs_confirmation`: 근거가 약하거나 교사 확인이 필요한 내용

`inferred`와 `needs_confirmation`은 사실처럼 확정하지 않는다. 교사는 모든 문장을 추가·수정·삭제할 수 있다. 확정본과 서버 기여에는 모든 문장 확인이 필요하고 확인된 태그만 포함한다. 선택적 로컬 편집 초안에는 미확인 문장도 보관할 수 있으며 확정본과 구분한다.

## 결과물

- canonical source: Zod로 검증한 `TeacherContextProfile` JSON
- 파생 결과물: YAML front matter를 포함한 UTF-8 Markdown 전체본·핵심본·모듈 선택본
- 전체본은 기존 문서 형식 2.0을 유지하며 7개 프로필 모듈, 수업 설계 실행 가이드, 수업별 작업 YAML, AI 실행 프롬프트를 포함한다.
- 핵심본 2.0은 교사가 검토한 전체·모듈 요약과 원칙·학급 지원·제약·AI 협업 지침을 원문과 순서대로 담고 중복 제거를 하지 않는다. 개별 진술 문장(claims), 근거 라벨, 미확인 문장 제외 안내, 수업별 작업 양식과 실행 프롬프트는 넣지 않는다. AI가 종합하고 교사가 확인한 내용임을 사용 규칙에 밝히며, 교사 진술 근거가 필요한 작업에는 전체본이나 모듈 선택본을 사용한다. 기준 시점 문단은 문서 앞에 한 번 둔다.
- 모듈 선택본은 7개 모듈 중 하나 이상과 원칙·학급 지원·제약 섹션을 선택한다. 포함 범위 안내, 메타데이터, 근거 표시, 개인정보 지침·경고, AI 협업 지침과 판단 경계는 항상 유지한다.
- 핵심본·모듈 선택본의 학급 맥락에는 한국 시간 기준 확정일(연결된 로컬 확정본) 또는 생성일(미연결·읽기 실패)을 표시한다.
- 결과 화면에서는 세 형식의 미리보기·복사·Markdown 다운로드를 제공하며 같은 문자열을 사용한다. 모듈 0개 선택 시 내보내기를 막는다. AI 활용 가이드에서는 같은 선택기로 형식별 Markdown을 내려받는다.
- 기존 짧은 AI 컨텍스트 복사는 Markdown 핵심본 복사로 교체한다. 전체 컨텍스트 복사·일반 텍스트 복사·인쇄와 기존 전체본 다운로드는 유지한다.
- 변형본 생성에 AI나 서버 호출을 사용하지 않으며, 변형본과 선택 상태는 저장하지 않는다. JSON 백업·기여 데이터·skill ZIP 참고 파일은 기존 전체본 계약을 유지한다.
- 선택 저장과 무관하게 모든 로컬 결과 기능 사용 가능
- 개인정보 경고를 확인하고 만든 문서는 경고 상태를 JSON·Markdown·화면에 그대로 보존

## 비목표

- 교사 전문성 평가, 심리검사, MBTI식 유형 분류
- 학생 개인 진단이나 개별 학생 기록
- 로그인 계정, 공개 프로필 조회, 광고 추적
- 원본 인터뷰 답변의 서버 저장
- 특정 AI 공급자에 종속된 문서 형식

## 성공 기준

- 로그인이 없어도 전체 흐름을 완료할 수 있다.
- 네 학교급과 역할별 질문 분기가 동작한다.
- 최대 네 개의 후속 질문과 7개 모듈 프로필이 생성된다.
- 교사가 문장 근거와 태그를 모두 확인할 수 있다.
- 유용한 학교·학급 맥락은 보존되고 개인정보 위험 입력은 AI 전송 전에 경고되며, 교사가 고치거나 그대로 계속할 수 있다.
- 재작성 오류나 개인정보 경고에서 문제가 있는 문장으로 바로 이동할 수 있다.
- 저장 동의가 없어도 Markdown을 온전히 받을 수 있다.
- 최종 경고가 남은 문서는 명시적 확인 후 내보내거나 선택적으로 로컬에 보관할 수 있지만 서버에 기여할 수 없다.
- 서버 기여 시 최종 프로필만 보관되고 삭제 코드로 익명 삭제할 수 있다.
- 로컬 저장은 기본 꺼짐이다. 원문 답변·검사 토큰·영수증·경고 확인 상태는 보관하지 않는다. 교사나 브라우저가 지울 때까지 보관하며 `/profiles`와 `/privacy`에서 모두 삭제하고 끌 수 있다.
