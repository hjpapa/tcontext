# AI 활용을 위한 교사 프로파일 컨텍스트

## 문서 사용 안내

이 문서는 나의 교육관, 수업 방식, 학급 맥락과 AI 협업 원칙을 설명하기 위한 기본 컨텍스트이다.
교과, 단원, 성취기준과 같은 정보는 작업할 때 별도로 추가한다.

## 프로파일 요약

학생의 읽기 선택을 존중하면서 여러 자료의 작성 주체, 근거, 목적을 비교하게 하고, 신뢰성에 대한 판단을 자기 말로 설명하도록 지원한다.

## 1. 교사 기본 프로파일과 현재 역할

도서관 수업과 자료 탐색 지원을 통해 읽기 선택의 폭을 넓히고 정보의 신뢰성을 판단하는 습관을 기른다.

- **직접 답변에 근거함:** 사서교사로서 학생이 관심에 맞는 읽을거리를 찾고 필요한 정보를 여러 자료에서 비교하도록 돕는다.
- **AI가 답변을 종합해 해석함:** 자료를 대신 골라 주기보다 선택 기준을 함께 세우는 역할은 읽기 자율성과 정보 판단 능력을 동시에 지원한다.

## 2. 교육관과 학생관

무엇을 읽었는지보다 왜 선택했고 어떤 근거로 믿을 만하다고 판단했는지를 설명하는 과정을 중요하게 본다.

- **직접 답변에 근거함:** 한 가지 정답 자료를 제시하기보다 서로 다른 형식과 관점을 가진 자료를 비교하게 한다.
- **AI가 답변을 종합해 해석함:** 선택 이유를 말하고 새로운 근거에 따라 판단을 바꾸는 경험은 학생이 독립적인 독자이자 정보 이용자로 성장하도록 돕는다.

## 3. 선호하는 수업 방식

짧은 판단 시범 뒤 개별 탐색, 짝 비교, 근거 공유의 순서로 읽기와 정보 활용 수업을 운영한다.

- **직접 답변에 근거함:** 자료를 볼 때 만든 주체, 작성 시점, 제시된 근거, 정보의 목적을 확인하는 과정을 소리 내어 보여 준다.
- **AI가 답변을 종합해 해석함:** 교사의 판단 과정을 먼저 모델링한 뒤 학생이 다른 자료에 같은 질문을 적용하면 점검 기준을 실제 탐색 행동으로 옮길 수 있다.

## 4. 현재 학급 또는 수업 집단의 기본 맥락

읽기 경험과 관심 주제가 달라도 탐색에 참여할 수 있도록 자료의 길이와 형식, 접근 경로를 다양하게 제공한다.

- **직접 답변에 근거함:** 같은 주제에서도 글, 그림 자료, 도표, 짧은 디지털 자료를 함께 제시하고 학생이 시작 자료를 선택하게 한다.
- **AI가 답변을 종합해 해석함:** 공통 판단 질문을 유지하면서 자료 형식을 다양화하면 읽기 속도를 비교하지 않고 모두가 신뢰성 검토에 참여할 수 있다.

## 5. 학생 참여와 정서 지원 원칙

개별 선택 기록에서 시작해 소규모 대화와 선택적 공유로 이어 가며 판단을 바꿀 수 있는 안전한 분위기를 만든다.

- **직접 답변에 근거함:** 전체 공유 전에 선택 이유를 메모하거나 짝에게 설명하게 하고, 발표 대신 질문을 제출하는 방식도 허용한다.
- **AI가 답변을 종합해 해석함:** 처음 판단을 공개적으로 방어하게 하기보다 근거를 보완할 시간을 주면 틀릴 부담을 낮추고 수정 가능한 판단을 장려할 수 있다.

## 6. 수업 자료·평가·피드백과 의사소통

자료의 신뢰성에 대한 결론보다 확인한 단서와 판단 과정을 살피고, 다음 탐색에 적용할 질문을 피드백한다.

- **직접 답변에 근거함:** 학생이 선택한 자료마다 확인한 단서, 아직 모르는 점, 추가로 비교할 자료를 간단한 기록표에 남기게 한다.
- **AI가 답변을 종합해 해석함:** 판단의 근거와 한계를 함께 기록하면 정답 맞히기보다 정보 검토 과정을 관찰하고 구체적으로 지원할 수 있다.

## 7. 현실적인 환경·제약과 디지털·AI 활용

한정된 수업 시간과 기기 접근 차이를 고려해 인쇄 자료와 디지털 자료를 함께 준비하고, AI가 제시한 정보도 같은 기준으로 검토한다.

- **직접 답변에 근거함:** AI는 비교 질문이나 검색어의 초안을 만드는 데 활용하되 출처, 사실, 저작권을 확인하지 않은 결과는 수업 자료로 사용하지 않는다.
- **AI가 답변을 종합해 해석함:** AI 산출물을 별도의 권위로 다루지 않고 다른 자료와 나란히 검토하면 정보 신뢰성 판단 원칙을 일관되게 적용할 수 있다.

## 수업 설계 시 고려할 기본 원칙

- 학생이 관심과 목적에 따라 시작 자료를 선택하게 한다.
- 만든 주체, 작성 시점, 근거, 목적을 공통 판단 질문으로 사용한다.
- 판단이 달라졌을 때 새로 확인한 근거와 수정 이유를 설명하게 한다.

### 학급 지원 시 고려사항

- 같은 주제를 여러 길이와 형식의 자료로 제공한다.
- 개별 메모, 짝 대화, 질문 제출, 전체 공유 중 다양한 참여 통로를 마련한다.
- 자료를 찾는 위치와 비교 순서를 시각적으로 안내한다.

### 현실적인 제약

- 기기 사용이 어려운 경우에도 같은 판단 질문을 적용할 수 있도록 인쇄 자료 묶음을 준비한다.
- 제한된 수업 시간에는 모든 자료를 다루기보다 대표 자료 두세 개를 깊게 비교하도록 지원한다.

## AI와 협업할 때의 기본 지침

- 학생 개인 정보 없이 주제, 읽기 목적, 사용할 자료 형식만으로 탐색 활동을 제안한다.
- 답을 대신 정하지 말고 학생이 출처와 근거를 확인할 질문을 만든다.
- 사실, 출처, 작성 시점, 저작권이 확인되지 않은 내용은 불확실하다고 표시한다.
- 디지털 자료와 함께 사용할 수 있는 인쇄 자료 대안을 제안한다.

## 확인한 분석용 태그

- **선호 수업 방식:** inquiry, discussion, blended
- **참여 우선순위:** choice, judgment, reflection, sharing
- **정서 지원 우선순위:** multiple_expression_modes, low_risk_participation, predictable_structure
- **평가 우선순위:** reasoning, self_reflection, observation
- **환경 제약:** limited_time, device_gap
- **AI 활용 경계:** no_personal_data, student_thinking_first, fact_check_required, copyright_review, teacher_final_judgment
