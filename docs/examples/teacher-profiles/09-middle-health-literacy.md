# AI 활용을 위한 교사 프로파일 컨텍스트

## 문서 사용 안내

이 문서는 나의 교육관, 수업 방식, 학급 맥락과 AI 협업 원칙을 설명하기 위한 기본 컨텍스트이다.
교과, 단원, 성취기준과 같은 정보는 작업할 때 별도로 추가한다.

## 프로파일 요약

학생 개인의 건강 경험을 드러내지 않으면서 공신력 있는 출처, 작성 시점, 근거를 비교해 일반 건강정보를 판단하도록 돕는다. 짧은 교육 시간에도 익명 질문, 가상 자료 비교, 비디지털 확인표를 활용해 안전하게 참여하고 판단 근거를 설명할 수 있게 지원한다.

## 1. 교사 기본 프로파일과 현재 역할

보건 업무와 건강교육을 연결하며, 개인에 대한 의료 판단이 아니라 누구나 사용할 수 있는 건강정보 판단 기준을 가르친다.

- **직접 답변에 근거함:** 건강교육 자료를 고를 때 공신력 있는 기관의 최신 자료인지 먼저 확인하고, 작성일과 근거가 분명하지 않으면 수업 자료로 사용하지 않는다.
- **AI가 답변을 종합해 해석함:** 제한된 교육 시간에는 여러 정보를 넓게 소개하기보다 반복해서 적용할 수 있는 출처 확인 절차를 익히게 하는 것이 이 역할의 수업 설계에 더 적합하다.

## 2. 교육관과 학생관

건강정보를 외우는 것보다 출처와 근거를 살피고 불확실할 때 추가 확인을 선택하는 과정을 중요한 학습으로 본다.

- **직접 답변에 근거함:** 학생에게 개인 경험이나 건강 상태를 설명하게 하지 않고, 공개된 일반 자료와 가상 상황을 통해 판단을 연습하게 한다.
- **AI가 답변을 종합해 해석함:** 정답을 빠르게 고르는 것보다 어떤 출처를 신뢰했고 무엇을 더 확인해야 하는지 설명하는 기회를 제공할 때 건강정보 판단의 주도성을 지원할 수 있다.

## 3. 선호하는 수업 방식

짧은 안내 뒤 여러 건강정보의 출처와 표현 방식을 비교하고, 판단 근거를 말하거나 기록하는 흐름을 선호한다.

- **직접 답변에 근거함:** 공공기관 안내, 광고성 문구, 출처가 불분명한 게시물을 나란히 제시하고 작성자·날짜·근거·목적을 확인하게 한다.
- **AI가 답변을 종합해 해석함:** 개인 메모 후 소규모 대화를 거쳐 전체 기준을 정리하면 공개 발언의 부담을 낮추면서 서로 다른 판단 근거를 비교하게 할 수 있다.

## 4. 현재 학급 또는 수업 집단의 기본 맥락

온라인 건강정보를 접한 경험과 출처 확인에 익숙한 정도가 서로 다를 수 있으므로, 모두가 같은 확인표와 예시에서 시작하도록 수업을 구조화한다.

- **직접 답변에 근거함:** 기기를 바로 사용할 수 없는 상황에도 참여할 수 있도록 인쇄 자료와 출처 확인표를 함께 준비한다.
- **AI가 답변을 종합해 해석함:** 자료의 길이와 용어 난이도를 달리한 선택지를 제공하면 공통 판단 기준은 유지하면서 각자 접근 가능한 경로를 선택하도록 지원할 수 있다.

## 5. 학생 참여와 정서 지원 원칙

개인 건강정보를 공개하지 않아도 질문하고 판단을 표현할 수 있는 저위험 참여 통로를 마련한다.

- **직접 답변에 근거함:** 이름을 수집하지 않는 질문함을 사용하고, 답변할 때에도 특정 경험을 추정하지 않고 모든 학생에게 적용되는 일반 원칙으로 설명한다.
- **AI가 답변을 종합해 해석함:** 말하기, 짧은 기록, 출처 표시 중 참여 방식을 선택하게 하면 민감한 주제에서도 개인 경험 노출 없이 학습 과정에 참여하도록 지원할 수 있다.

## 6. 수업 자료·평가·피드백과 의사소통

자료의 최신성과 신뢰성을 확인하고, 학생이 사용한 판단 근거와 다음 확인 행동을 중심으로 피드백한다.

- **직접 답변에 근거함:** 출처 이름만 맞히게 하지 않고 누가, 언제, 어떤 근거로 만들었는지와 다른 자료로 교차 확인할 필요가 있는지를 살핀다.
- **AI가 답변을 종합해 해석함:** 피드백을 “판단 근거 한 가지 보완하기”처럼 다음 행동으로 제시하면 결과를 점수화하지 않고 정보 판단 과정을 수정하도록 도울 수 있다.

## 7. 현실적인 환경·제약과 디지털·AI 활용

짧은 수업 시간과 기기 접근 차이를 고려해 핵심 기준을 간결하게 반복하며, AI는 일반 교육자료 초안을 만드는 제한된 도구로 사용한다.

- **직접 답변에 근거함:** AI에는 학생의 건강·상담·보건실 이용 정보를 입력하지 않고, AI가 만든 건강정보는 최신 공신력 출처에서 직접 다시 확인한다.
- **AI가 답변을 종합해 해석함:** AI가 자료마다 작성일·출처·불확실성을 표시하고 비디지털 대안을 함께 제안하게 하면 사실 확인과 접근 지원을 동시에 검토하기 쉽다.

## 수업 설계 시 고려할 기본 원칙

- 개인 경험을 요구하지 않는 가상 자료로 건강정보 판단을 연습한다.
- 작성자, 작성일, 근거, 목적, 교차 확인의 순서로 출처를 살핀다.
- 판단 결과보다 사용한 근거와 추가 확인 행동을 설명하게 한다.

### 학급 지원 시 고려사항

- 이름을 수집하지 않는 질문 통로와 참여 보류 선택을 제공한다.
- 말, 짧은 기록, 출처 표시 중 생각을 표현할 방식을 선택하게 한다.
- 어려운 용어에는 쉬운 말 풀이를 붙이고 같은 내용의 인쇄 자료를 제공한다.

### 현실적인 제약

- 교육 시간이 짧을 때는 핵심 출처 기준 두세 가지를 반복 적용할 수 있는 짧은 자료를 제공한다.
- 기기를 함께 사용할 수 없을 때도 같은 판단 활동을 할 수 있도록 인쇄 자료와 비디지털 확인표를 제공한다.
- 자료 준비 시간이 제한될 때는 최신 여부를 다시 확인할 출처 목록과 재사용 가능한 비교 양식을 유지한다.

## AI와 협업할 때의 기본 지침

- 학생의 건강정보, 상담 내용, 보건실 이용 정보나 개인을 식별할 수 있는 내용을 입력하지 않는다.
- 건강정보에는 확인 가능한 최신 출처와 작성 시점을 제시하고, 불확실한 내용은 불확실하다고 표시하게 한다.
- 개인 의료 조언이나 진단을 생성하지 말고 일반 건강교육 자료와 출처 확인 질문만 제안하게 한다.
- AI 산출물은 교사가 공신력 있는 원문에서 사실을 확인한 뒤 수업 맥락에 맞게 수정한다.
- AI가 자료 초안 작성에 사용되었다면 사용 범위와 교사가 검토한 사실을 수업 자료에 알린다.

## 확인한 분석용 태그

- **선호 수업 방식:** inquiry, discussion, blended
- **참여 우선순위:** questioning, judgment, reflection
- **정서 지원 우선순위:** psychological_safety, low_risk_participation, multiple_expression_modes
- **평가 우선순위:** reasoning, self_reflection, observation
- **환경 제약:** limited_time, device_gap
- **AI 활용 경계:** no_personal_data, teacher_final_judgment, fact_check_required, disclose_ai_use
