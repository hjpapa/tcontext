# 개인정보 보호 설계

## 기본 원칙

TContext는 데이터 최소화, 목적 제한, 사용자 검토, 선택 동의를 기본값으로 삼는다. 서비스 이용과 Markdown 다운로드에는 로그인이나 데이터베이스 저장이 필요하지 않다.

입력해서는 안 되는 정보:

- 교사·학생 이름, 구체적인 학교명, 반·학급을 특정하는 명칭
- 전화번호, 이메일, 주소, 생년월일, 주민등록번호 형식
- 학생 사진, 연락처, 상담·건강·진단·가정환경·생활기록부 내용
- 여러 정보의 조합으로 특정 개인을 추정할 수 있는 서술

학생을 규정하는 표현 대신 필요한 지원과 관찰 가능한 수업 조건을 기술하도록 안내한다.

## 단계별 데이터 흐름

### 1. 브라우저 입력

- 진행 상태는 기본적으로 `sessionStorage`에만 저장한다.
- 탭을 닫으면 제거되는 것이 기본이다.
- 사용자가 명시적으로 “이 기기에 임시 저장”을 켠 경우에만 `localStorage`를 사용한다.
- “모든 기록 삭제”로 두 저장소의 TContext 키를 즉시 지울 수 있다.

### 2. AI 전송 전

- 클라이언트 규칙 기반 탐지기가 이메일, 전화번호, 주민등록번호형 숫자, 생년월일, 구체 주소, 실명 가능 표현, 민감한 상담·진단 표현을 검사한다.
- 위험이 탐지되면 답변을 서버나 OpenAI로 전송하지 않는다.
- 문제 구간, 이유, 지원 중심 대체 문장 예시를 보여주고 사용자가 직접 수정한 뒤 재제출하도록 한다.

### 3. 서버와 OpenAI

- OpenAI 호출은 Next.js Route Handler에서만 수행한다.
- 공식 Responses API와 JSON Schema Structured Outputs를 사용한다.
- 가능하면 `store: false`를 적용한다.
- 서버에서도 동일한 개인정보 규칙을 다시 검사한다.
- 최종 생성 전 별도 개인정보 검토 모델을 통과한다.
- 애플리케이션 로그에는 질문, 답변, 프로필 본문을 남기지 않는다. 모델명, 처리 시간, 토큰 사용량, 성공 여부만 구조화해 기록한다.

### 4. 선택적 Supabase 저장

- 체크박스는 기본 해제 상태다.
- 저장 목적, 항목, 365일 보유기간을 확인하고 명시적으로 동의한 경우에만 저장한다.
- canonical 최종 프로필 JSON, 동일 JSON에서 만든 Markdown, 교사가 확인한 태그, 개인정보 검토 결과와 운영 메타데이터만 저장한다.
- 원본 인터뷰 답변, 이름, 이메일, IP 주소, 학교명, 학생명, 브라우저 식별자는 저장하지 않는다.
- `SUPABASE_SECRET_KEY`는 서버 전용 모듈에서만 읽는다. 브라우저 번들에 포함하지 않는다.
- RLS를 강제하고 `anon`, `authenticated`, `public`에는 읽기·쓰기 정책이나 테이블 권한을 주지 않는다.

## 삭제 코드

저장 시 서버가 충분히 긴 무작위 코드를 만들고, 브라우저에는 원문을 한 번만 반환한다. 데이터베이스에는 서버 비밀값과 결합한 SHA-256/HMAC 해시만 저장한다. 사용자는 제출 ID와 삭제 코드로 `/delete`에서 삭제할 수 있으며, 공개 조회 API는 제공하지 않는다.

삭제 코드 분실 시 로그인 계정이나 이메일이 없으므로 제출물을 찾아주거나 삭제하기 어려울 수 있다.

## 보유기간과 자동 삭제

- 기본 보유기간: 동의 시점부터 365일
- `retention_until = consented_at + DATA_RETENTION_DAYS`
- Vercel Cron이 매일 보호된 API를 호출해 `retention_until < now()`인 행을 삭제한다.
- Cron 응답과 로그에는 삭제 건수만 포함하고 프로필 본문은 포함하지 않는다.

## 로그 정책

허용:

- 요청 유형, 모델명, 성공 여부, 처리 시간, 토큰 사용량
- 개인정보 탐지 발생 여부와 규칙 식별자
- 저장·삭제 성공 여부와 건수

금지:

- 원본 인터뷰 답변
- 프로필 JSON 또는 Markdown 본문
- 삭제 코드, 해시, Supabase Secret Key, OpenAI API Key
- 이름, IP 주소, 학교명 등 식별 가능 정보

## 탐지기의 한계

규칙 기반 탐지는 모든 실명·문맥상 식별 정보·변형 표기를 찾을 수 없다. AI 검토 역시 완전한 보장을 제공하지 않는다. 그래서 두 탐지 단계를 보조 장치로만 사용하고, 교사의 최종 확인과 “저장하지 않기” 선택을 가장 중요한 통제로 둔다.
