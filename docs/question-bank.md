# 질문 은행

## 구성 원칙

각 인터뷰는 공통 질문 9개, 선택한 학교급 질문 1개, 선택한 역할 질문 1개로 총 11개다. 모든 경로가 7개 프로필 모듈을 빠짐없이 다룬다. AI 후속 질문은 별도이며, 구체화가 꼭 필요할 때만 전체 인터뷰에서 최대 4개까지 추가한다.

각 질문은 하나의 핵심 판단만 쉬운 말로 묻는다. 비유는 `나침반`, `운전 습관`, `리셋 버튼`을 사용한 3개 문항에만 제한하고, 예시는 짧고 중립적인 문장으로 제공한다. 화면에서는 답변 예시를 기본적으로 접어 두고 사용자가 필요할 때 열 수 있게 한다.

질문은 교사를 평가하지 않고 실제 수업 경험과 판단을 구체화한다. 학생 이름, 학교명, 진단, 성적 등 개인을 식별할 수 있는 사례는 요구하지 않는다.

## 공통 질문 9개

| ID                             | 모듈             | 질문 초점                                     |
| ------------------------------ | ---------------- | --------------------------------------------- |
| `common-role-focus`            | 기본 프로필·역할 | 지금 더 잘하거나 더 알아보고 싶은 교육 관심사 |
| `common-good-lesson`           | 교육관·학생관    | 참여나 이해가 좋아졌을 때 교사가 한 행동 하나 |
| `common-educational-principle` | 교육관·학생관    | 어떤 상황에서도 지키려는 수업 원칙 하나       |
| `common-lesson-flow`           | 선호 수업        | 새 수업을 준비할 때 가장 먼저 정하는 것       |
| `common-adaptive-tendency`     | 선호 수업        | 예상과 달라진 수업에서 드러나는 운영 성향     |
| `common-class-support`         | 학급 맥락        | 반 전체의 참여에 필요한 조건 하나             |
| `common-assessment-feedback`   | 자료·평가·피드백 | 피드백 전에 먼저 살펴보는 학습 정보 하나      |
| `common-environment`           | 환경·AI          | 하고 싶은 수업을 어렵게 만드는 현실 문제      |
| `common-ai-boundaries`         | 환경·AI          | AI를 활용해도 교사가 직접 결정할 일           |

`common-adaptive-tendency`는 교사에게 고정된 성격 유형이나 점수를 붙이기 위한 문항이 아니다. 계획을 고쳐 이어 가는 쪽과 흐름에 맞춰 새 방향을 잡는 쪽 중 어느 쪽에 가까운지 묻되, 둘 사이이거나 상황마다 다르다고 답할 수 있다. 여러 답변에서 같은 선택이 반복될 때만 수정 가능한 수업 운영 경향으로 해석한다.

## 학교급 질문 1개

- 유치원 — `kindergarten-transition`: 놀이가 끝나고 다음 활동으로 갈 때 쓰는 신호
- 초등학교 — `elementary-group-sharing`: 모두에게 말하거나 해 볼 기회를 주는 방법
- 중학교 — `middle-autonomy-participation`: 선택권을 주면서 안전한 참여를 지키는 규칙
- 고등학교 — `high-assessment-pressure`: 시험이나 평가가 많은 때에도 다시 고치게 하는 방법

모든 학교급 질문은 `participation_and_emotion` 모듈의 근거를 수집한다.

## 역할 질문 1개

| 역할              | 질문 초점                                               |
| ----------------- | ------------------------------------------------------- |
| 담임교사          | 학급 분위기를 다시 차분하게 만드는 루틴                 |
| 교과전담·교과교사 | 여러 반의 반응에 따라 가장 먼저 바꾸는 수업 요소        |
| 특수교사          | 같은 목표를 여러 방법으로 배우게 할 때 먼저 바꾸는 요소 |
| 상담교사          | 상담 내용을 지키며 교실 지원을 요청하는 원칙            |
| 보건교사          | 건강교육 자료를 고를 때 가장 먼저 보는 기준             |
| 사서교사          | 자료가 믿을 만한지 확인할 때 가장 먼저 보게 하는 것     |
| 관리자·교육 리더  | 새로운 수업을 시도하려는 교사에게 먼저 마련하는 지원    |
| 기타 역할         | 학습자나 교사에게 가장 자주 주는 도움                   |

## AI 후속 질문 기준

- 답변의 의미가 이미 충분하면 만들지 않는다.
- 실제 수업 경험을 구체화할 가치가 있을 때만 한 번에 하나를 묻는다.
- 앞서 답한 내용을 반복해서 묻지 않는다.
- 채점·평가·심리검사처럼 들리는 질문을 만들지 않는다.
- 학생 개인 정보나 구체적인 식별 가능 사례를 요구하지 않는다.
- 자연스러운 한국어 1~2문장으로 제한한다.
- 누적 4개에 도달하면 추가 생성하지 않는다.
