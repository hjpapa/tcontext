# 질문 은행

## 구성 원칙

각 인터뷰는 공통 질문 9개, 선택한 학교급 질문 1개, 선택한 역할 질문 1개로 총 11개다. 모든 경로가 7개 프로필 모듈을 빠짐없이 다룬다. AI 후속 질문은 별도이며, 구체화가 꼭 필요할 때만 전체 인터뷰에서 최대 4개까지 추가한다.

각 질문은 하나의 핵심 판단만 묻는다. 비유는 필요한 문항에만 제한하고, 예시는 짧고 중립적인 문장으로 제공한다. 화면에서는 답변 예시를 기본적으로 접어 두고 사용자가 필요할 때 열 수 있게 한다.

질문은 교사를 평가하지 않고 실제 수업 경험과 판단을 구체화한다. 학생 이름, 학교명, 진단, 성적 등 개인을 식별할 수 있는 사례는 요구하지 않는다.

## 공통 질문 9개

| ID                             | 모듈             | 질문 초점                                 |
| ------------------------------ | ---------------- | ----------------------------------------- |
| `common-role-focus`            | 기본 프로필·역할 | 현재 가장 깊이 탐구하고 싶은 교육 관심사  |
| `common-good-lesson`           | 교육관·학생관    | 배움이 이어진 순간에 교사가 한 핵심 행동  |
| `common-educational-principle` | 교육관·학생관    | 선택이 충돌해도 유지하는 교육 원칙        |
| `common-lesson-flow`           | 선호 수업        | 수업 설계에서 가장 먼저 중심에 놓는 요소  |
| `common-adaptive-tendency`     | 선호 수업        | 계획과 다르게 흘러갈 때 가장 먼저 한 행동 |
| `common-class-support`         | 학급 맥락        | 수업 집단의 참여와 학습을 좌우하는 조건   |
| `common-assessment-feedback`   | 자료·평가·피드백 | 다음 피드백을 정할 때 확인하는 학습 근거  |
| `common-environment`           | 환경·AI          | 수업 아이디어의 실행을 가로막는 현실 조건 |
| `common-ai-boundaries`         | 환경·AI          | AI를 활용해도 교사가 직접 판단할 일       |

`common-adaptive-tendency`는 교사에게 유형명을 붙이기 위한 문항이 아니다. 계획이 어긋난 실제 장면에서 먼저 내린 판단과 행동을 확인하고, 여러 답변에서 같은 선택이 반복될 때만 수정 가능한 수업 운영 경향으로 해석한다.

## 학교급 질문 1개

- 유치원 — `kindergarten-transition`: 놀이에서 다음 일과로 전환할 때 안정적인 참여를 돕는 신호
- 초등학교 — `elementary-group-sharing`: 모둠·전체 활동의 참여 기회를 고르게 만드는 장치
- 중학교 — `middle-autonomy-participation`: 선택권과 안전한 참여를 함께 지키는 경계
- 고등학교 — `high-assessment-pressure`: 평가 부담 속에서도 다시 시도하게 돕는 수업 장치

모든 학교급 질문은 `participation_and_emotion` 모듈의 근거를 수집한다.

## 역할 질문 1개

| 역할              | 질문 초점                                                  |
| ----------------- | ---------------------------------------------------------- |
| 담임교사          | 학급의 흐름을 가장 먼저 회복시키는 루틴                    |
| 교과전담·교과교사 | 여러 학급에서도 유지하는 수업 원칙                         |
| 특수교사          | 학습 목표에 접근하는 방법을 다양화할 때 먼저 조정하는 요소 |
| 상담교사          | 상담 내용을 보호하며 교실 지원으로 연결하는 경계           |
| 보건교사          | 건강교육 자료를 선택할 때 가장 먼저 확인하는 기준          |
| 사서교사          | 학습자가 자료의 신뢰성을 판단할 때 먼저 확인할 기준        |
| 관리자·교육 리더  | 교사의 새로운 수업 시도를 위해 가장 먼저 제공할 지원       |
| 기타 역할         | 학습자나 교사에게 가장 자주 제공하는 지원                  |

## AI 후속 질문 기준

- 답변의 의미가 이미 충분하면 만들지 않는다.
- 실제 수업 경험을 구체화할 가치가 있을 때만 한 번에 하나를 묻는다.
- 앞서 답한 내용을 반복해서 묻지 않는다.
- 채점·평가·심리검사처럼 들리는 질문을 만들지 않는다.
- 학생 개인 정보나 구체적인 식별 가능 사례를 요구하지 않는다.
- 자연스러운 한국어 1~2문장으로 제한한다.
- 누적 4개에 도달하면 추가 생성하지 않는다.
