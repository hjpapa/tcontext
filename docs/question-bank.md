# 질문 은행

## 구성 원칙

각 인터뷰는 공통 질문 12개, 선택한 학교급 질문 1개, 선택한 역할 질문 1개로 총 14개다. 모든 경로가 7개 프로필 모듈을 빠짐없이 다룬다. AI 후속 질문은 별도이며, 구체화가 꼭 필요할 때만 전체 인터뷰에서 최대 4개까지 추가한다.

각 질문은 하나의 핵심 판단만 쉬운 말로 묻는다. 비유는 담임교사 역할 질문의 `리셋 버튼` 하나만 사용하고, 예시는 정답처럼 보이지 않는 짧은 2문장으로 제공한다. 화면에서는 답변 예시를 기본적으로 접어 두고 사용자가 필요할 때 열 수 있게 한다.

질문은 교사를 평가하지 않고 실제 수업 경험과 판단을 구체화한다. 사람 이름, 연락처, 식별번호, 생년월일, 상세 주소, 정확한 학교나 반의 고유명, 개인과 연결되는 민감정보는 요구하지 않는다. 학교급, 교과, 대략적인 인원, 수업 환경과 집단의 참여 경향처럼 개인을 특정하지 않는 수업 맥락은 답할 수 있다.

## 공통 질문 12개

| ID                             | 모듈             | 질문 초점                                             |
| ------------------------------ | ---------------- | ----------------------------------------------------- |
| `common-role-focus`            | 기본 프로필·역할 | 지금 더 잘하거나 더 알아보고 싶은 교육 관심사         |
| `common-personal-value`        | 기본 프로필·역할 | 개인적 가치가 드러나는 실제 선택                      |
| `common-good-lesson`           | 교육관·학생관    | 참여나 이해가 좋아졌을 때 교사가 한 행동 하나         |
| `common-educational-principle` | 교육관·학생관    | 원칙이 진도 같은 다른 요구와 부딪힐 때 먼저 챙기는 것 |
| `common-lesson-flow`           | 선호 수업        | 새 수업을 준비할 때 가장 먼저 정하는 것               |
| `common-adaptive-tendency`     | 선호 수업        | 예상과 달라진 수업에서 계획을 바꿀지 정할 때 보는 것  |
| `common-class-support`         | 학급 맥락        | 수업 방식을 정할 때 염두에 두는 학급의 분위기나 특징  |
| `common-assessment-feedback`   | 자료·평가·피드백 | 피드백 전에 먼저 살펴보는 학습 정보 하나              |
| `common-environment`           | 환경·AI          | 시간·공간·기기처럼 수업에서 감안하는 학교 사정        |
| `common-ai-boundaries`         | 환경·AI          | AI를 활용해도 교사가 직접 결정할 일                   |
| `common-ai-task`               | 환경·AI          | AI에게 가장 먼저 맡기고 싶은 작업                     |
| `common-ai-response`           | 환경·AI          | 검토하기 편한 AI 응답 방식                            |

`common-adaptive-tendency`는 고정된 성격 유형 대신 계획을 바꿀지 그대로 갈지 정할 때 무엇을 보는지 묻는다. 개인적 가치 문항은 가치가 드러나는 선택을, 교육 원칙 문항은 다른 요구와 충돌할 때의 기준을 묻는다. AI 작업과 응답 선호는 경험이 없어도 답하거나 건너뛸 수 있는 문항이다.

2026-11-01(프롬프트 2.2)에 질문이 어색하고 이해하기 어렵다는 의견을 반영해 문장을 다듬었다. ID·모듈·묻는 판단은 그대로 두고 다음을 바꿨다.

- 추상 명사("판단하는 신호", "현실 조건", "학급의 상황")를 "무엇을 보고", "학교 사정", "분위기나 특징"처럼 바로 떠올릴 수 있는 말로 바꿨다.
- `common-educational-principle`의 `나침반` 비유를 빼고 "진도 같은 다른 요구"로 부딪히는 상황을 보여 준다.
- "수업을 준비할 때"로 시작하던 세 질문 중 두 질문의 도입을 바꿨다.
- `common-environment`는 시간·공간·기기를 질문에 직접 예로 든다.
- 유치원 공통 질문, `high-assessment-pressure`, 특수교사·상담교사 역할 질문도 같은 기준으로 다듬었다.

유치원을 선택하면 공통 질문의 ID와 모듈은 유지하되 학생·과제·교과 중심 표현을 유아·놀이·일과·관찰 맥락으로 바꾼다. 개인적 가치 문항은 성격 검사처럼 유형화하지 않고, 교사가 직접 밝힌 가치 하나와 교육 장면에서 드러나는 행동만 다룬다.

## 학교급 질문 1개

- 유치원 — `kindergarten-transition`: 다음 활동을 알아차리고 편안하게 이동하도록 돕는 신호
- 초등학교 — `elementary-group-sharing`: 모두가 한 번씩 참여하도록 돕는 방법
- 중학교 — `middle-autonomy-participation`: 활동 방법을 고를 때 함께 지키는 규칙
- 고등학교 — `high-assessment-pressure`: 평가가 이어지는 시기에도 다시 고치게 하는 방법

모든 학교급 질문은 `participation_and_emotion` 모듈의 근거를 수집한다.

## 역할 질문 1개

| 역할              | 질문 초점                                               |
| ----------------- | ------------------------------------------------------- |
| 담임교사          | 학급 분위기를 다시 차분하게 만드는 루틴                 |
| 교과전담·교과교사 | 여러 반의 반응에 따라 가장 먼저 바꾸는 수업 요소        |
| 특수교사          | 같은 목표를 여러 방법으로 배우게 할 때 먼저 바꾸는 요소 |
| 상담교사          | 상담 내용을 지키며 교실 지원을 요청하는 원칙            |
| 보건교사          | 건강교육 자료를 고를 때 가장 먼저 보는 기준             |
| 사서교사          | 자료가 믿을 만한지 확인할 때 가장 먼저 보게 하는 것     |
| 관리자·교육 리더  | 새로운 수업을 시도하려는 교사에게 먼저 마련하는 지원    |
| 기타 역할         | 학습자나 교사에게 가장 자주 주는 도움                   |

## AI 후속 질문 기준

- 답변의 의미가 이미 충분하면 만들지 않는다.
- 실제 수업 경험을 구체화할 가치가 있을 때만 한 번에 하나를 묻는다.
- 앞서 답한 내용을 반복해서 묻지 않는다.
- 채점·평가·심리검사처럼 들리는 질문을 만들지 않는다.
- 학생 개인 정보나 구체적인 식별 가능 사례를 요구하지 않는다.
- 물음표 하나로 끝나는 한 문장, 80자 이내의 평소 말로 쓴다. 자세한 문장 규칙은 [프롬프트 설계](prompt-design.md)의 후속 질문 절을 따른다.
- 누적 4개에 도달하면 추가 생성하지 않는다.
